Privacy Policy

Last updated: November 23, 2026

1. Who we are

Twitch Moments is a personal tool used only by the owner of the YouTube channel "Twitch Moments". Contact: twitchmomentsworld@gmail.com

2. Use of YouTube API Services

This tool uses YouTube API Services (YouTube Data API v3). By using it, you agree to be bound by the YouTube Terms of Service: https://www.youtube.com/t/terms

Google Privacy Policy: https://policies.google.com/privacy

3. Data we access

When the channel owner signs in with Google (OAuth 2.0), the tool accesses:

- the name of the YouTube channel (to check the right channel is connected);

- the permission to upload videos to that channel.

We do not access comments, subscribers, analytics, contacts or any other personal data.

4. How we use the data

The data is used only to upload clips that the channel owner validated, to the owner's own channel. Nothing else.

5. Storage

The OAuth access token is stored only on the owner's own computer, in a local file. It is never sent to any server other than Google's. We do not keep any copy of YouTube data on any server.

6. Sharing

We do not share, sell or transfer any data to anyone.

7. Cookies

This tool does not use cookies and does not store information on users' devices other than the local token described above. This website does not use cookies of its own.

8. Revoking access and deleting data

You can revoke the tool's access at any time on the Google security settings page: https://myaccount.google.com/connections

To delete the stored token, delete the local token file or write to twitchmomentsworld@gmail.com: we delete it within 7 days.

9. Changes

If this policy changes, the new version is published on this page with a new date.
