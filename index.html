Twitch Moments

Uses YouTube API Services

Twitch Moments is a small personal tool that turns the funniest moments of French Twitch live streams into short vertical videos, and uploads them to our own YouTube channel "Twitch Moments" using the YouTube API Services (YouTube Data API v3).

Twitch Moments est un petit outil personnel qui transforme les moments les plus drôles des lives Twitch français en vidéos verticales courtes, et les envoie sur notre propre chaîne YouTube « Twitch Moments » grâce aux Services API YouTube.

How it works:

1. The tool finds funny moments in a stream replay, cuts them, adds subtitles and credits the streamer.

2. The channel owner watches every clip and validates it by hand.

3. Only validated clips are uploaded to our channel with videos.insert, as private and scheduled.

This tool is used only by the owner of the Twitch Moments channel. It is not offered to other users.
